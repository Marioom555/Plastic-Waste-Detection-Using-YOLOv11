This project focuses on leveraging advanced computer vision techniques to detect and classify plastic waste in various environments. Using the YOLOv11 architecture combined with semantic segmentation, the system achieves high accuracy in identifying plastic waste while providing pixel-level annotations for precise localization.
Technologies Used
* Framework: PyTorch/TensorFlow (as applicable)
* Model: YOLOv11 for object detection and a segmentation model for pixel-wise classification.
* Tools: OpenCV, NumPy,and related libraries for data processing .

* Dataset
This project uses a curated dataset of plastic waste images annotated for both object detection and segmentation tasks. Details about the dataset and preprocessing steps can be found in the data/ directory.
